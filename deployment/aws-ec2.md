# AWS EC2 Deployment

## Instance Type

- Ubuntu 24.04
- t2.micro

## Required Software

- Docker
- Docker Compose
- Kubernetes

## Deployment Steps

1. Launch an EC2 instance.

2. Clone the repository.

3. Install Docker.

4. Install Kubernetes.

5. Start PostgreSQL.

6. Start Redis.

7. Deploy microservices.

8. Deploy the React frontend.
